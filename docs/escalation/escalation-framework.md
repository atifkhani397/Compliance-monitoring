# MACMS Escalation Framework

## 1. Overview
Defines human-in-the-loop escalation paths for Compliance Officers based on alert priority, confidence scores, and potential regulatory liability.

## 2. Escalation Tiers
- **Tier 1**: Compliance Analyst (P3/P4 alerts).
- **Tier 2**: Senior Compliance Manager (P2 alerts).
- **Tier 3**: Chief Compliance Officer / Legal Counsel (P1-CRITICAL alerts).
