# MACMS Inter-Agent Conflict Taxonomy

## 1. Overview
Defines categories of inter-agent conflict (False Positive Discrepancies, Cross-Jurisdictional Rule Collisions, Data Freshness Mismatches).

## 2. Taxonomy Structure
- **Type A**: Severity Discrepancy (TM rate Critical vs CS rate Low).
- **Type B**: Policy Mapping Collision (RU rule update conflicts with active desk exemption).
